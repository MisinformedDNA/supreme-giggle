# 🎭 Amusing Console Application

Welcome to the **Amusing Console** - your daily dose of fun in the terminal! This C# console application is designed to entertain and amuse with various interactive features.

## ✨ Features

### 🎨 ASCII Art Gallery
View a collection of cute ASCII art characters and animations, displayed with colorful effects.

### 😂 Joke Generator
Enjoy a collection of programming jokes, puns, and general humor with interactive punchline reveals.

### ✂️ Rock Paper Scissors
Play the classic game against the computer in a best-of-3 match with emojis and colorful feedback.

### 🔮 Matrix Effect
Experience a cool Matrix-style falling character effect (auto-stops after 10 seconds or when you press a key).

### 🌈 Colorful Text Demo
Watch rainbow text effects and blinking animations that showcase console color capabilities.

### 💭 Inspirational Quote Generator
Get random inspirational quotes from famous personalities with typewriter effects.

## 🚀 How to Run

### Prerequisites
- .NET 8.0 or later installed on your system

### Running the Application

1. **Clone or download** this repository
2. **Navigate** to the project directory:
   ```bash
   cd supreme-giggle
   ```
3. **Run** the application:
   ```bash
   dotnet run
   ```

Alternatively, you can build and run:
```bash
dotnet build
dotnet run --project AmusingConsole.csproj
```

## 🎮 How to Use

1. When the application starts, you'll see a welcome animation
2. Choose from the menu options by pressing the corresponding number key:
   - Press `1` for ASCII Art Gallery
   - Press `2` for Joke Generator
   - Press `3` for Rock Paper Scissors
   - Press `4` for Matrix Effect
   - Press `5` for Colorful Text Demo
   - Press `6` for Inspirational Quotes
   - Press `Q` to quit
3. Follow the on-screen instructions for each feature
4. Press any key to return to the main menu after each activity
